# 苏州大学预推免机试真题库

本目录收录了2024年和2025年苏州大学预推免计算机学院机试的真题，方便导入在线评测系统（OJ）。

## 目录结构

```
problems/
├── README.md           # 本文件
├── gen_all_testdata.py # 统一测试数据生成器
├── suzhou_2024/       # 2024年真题（8道）
└── suzhou_2025/       # 2025年真题（7道）
```

## 每道题的文件结构

每道题的目录下包含：
- `description.md` - 题面描述（含输入输出格式、样例、数据范围）
- `std.py` - Python 3 标准参考程序
- `01.in` ~ `10.in` - 10组测试点输入文件
- `01.out` ~ `10.out` - 10组测试点标准输出（由std.py生成）

## 使用说明

### 重新生成测试数据
```bash
python gen_all_testdata.py
```

### 验证某道题的标准程序
```bash
# 进入题目目录，用标准程序生成输出
python < problem.in > output.txt
# 或
cat problem.in | python std.py > output.txt
```

### 测试数据强度
- 01~05：样例数据 + 边界数据
- 06~10：大规模随机数据（部分题目包含 n=10^5 级别测试）

**注意**：部分题目（链表、二叉树、蛇形矩阵等）由于原题以类/结构体形式提供，
在OJ系统中可能需要适配为函数接口形式，暂无完整导入材料。
