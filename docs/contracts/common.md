# 公共契约

> 所有模块共享的契约：响应信封、API 前缀、通用错误码、分页契约。改契约前先读本文件。

## 响应信封

所有 API 统一响应信封 `{ code, message, data }`，统一前缀 `/api/v1`。

成功：

```json
{ "code": 0, "message": "ok", "data": { } }
```

失败：

```json
{
  "code": 2003,
  "message": "无权限",
  "data": null
}
```

- `code=0` 表示成功；非 0 表示失败，取对应错误码（见下）
- 错误码不可为 0（0 仅代表成功）
- 框架层参数校验失败（FastAPI 422，含 Query / Path / Body）由全局异常处理器统一转换为
  `1001` / HTTP 400 信封响应，不返回原生 `{"detail": [...]}` 结构
- **message 语言协商**：业务代码统一抛中文消息，异常处理出口按请求 `Accept-Language`
  （`zh-CN` 默认 / `en-US`）经 `app/core/i18n.py` 目录翻译为英文，未命中回退中文；
  错误码 `code` 不受语言影响。前端 `api/http.ts` 每次请求自动携带界面语言作为
  `Accept-Language`

### 实现约定

- 信封与分页是泛型 Pydantic 契约：`ApiResponse[T]`（`app/utils/response.py`）、
  `PaginatedResponse[T]`（`app/utils/pagination.py`），路由以
  `response_model=ApiResponse[Xxx]` 声明响应类型
- 路由返回 `ok(...)` 信封实例；Service 返回 Pydantic 响应模型；
  不得手工拼装响应字典、不得在响应出口调用 `model_dump`
- 错误信封仅由全局异常处理器（`app/core/exceptions.py`）经 `error(...)` 产生

## 通用错误码

### 参数校验 `10xx`

| 错误码 | HTTP | 说明 |
| --- | --- | --- |
| 1001 | 400 | 参数格式错误（类型 / 长度 / 范围不符合要求） |
| 1002 | 400 | 缺失必填参数 |

### 认证 `20xx`

| 错误码 | HTTP | 说明 |
| --- | --- | --- |
| 2001 | 401 | 未登录 / 未提供认证信息 |
| 2002 | 401 | 凭证已过期（会话过期） |
| 2003 | 403 | 无权限（已认证但角色不满足） |
| 2004 | 401 | 凭证无效（Token / 验证码错误） |

> `2003` 同时覆盖资源级越权（非所有者访问他人私有资源）；模块可新增专属越权码，如 `PROBLEM_NOT_ACCESSIBLE`。

### 资源 `30xx`

| 错误码 | HTTP | 说明 |
| --- | --- | --- |
| 3001 | 404 | 资源不存在 |
| 3002 | 409 | 状态冲突（如发布未验题、报名截止后提交） |
| 3003 | 409 | 资源重复（如重复报名、重复申请） |

### 频控 `40xx`

| 错误码 | HTTP | 说明 |
| --- | --- | --- |
| 4001 | 429 | 发送过频（验证码重发间隔 / 提交冷却） |
| 4002 | 429 | 触发限流（登录尝试超次 / 全局判题并发上限） |

### 系统异常 `50xx`

| 错误码 | HTTP | 说明 |
| --- | --- | --- |
| 5000 | 500 | 内部错误（不暴露详情） |
| 5001 | 502 | 上游服务调用失败（对象存储 / 沙箱链路） |

## 分页契约

- 列表接口统一 `?page=1&page_size=20`（`page ≥ 1`，`page_size ≤ 100`）
- 返回结构：`{ items, total, page, page_size }`
- 需要按时间游标的分页在具体模块接口标注

## 新增错误码规则

- 通用错误码（上表）已有对应场景时，优先复用，不新增
- 模块专属错误码写在对应模块契约文件的「错误码」节，命名 `UPPER_SNAKE_CASE`，并标注 HTTP 与触发场景
- 新增错误码必须更新本文件或对应模块契约文件，并在代码中引用错误码常量，不写死数字
