# 比赛运行中题目不锁定

- 日期：2026-08-15
- 状态：已采纳

## 背景

比赛中比赛题目可能被编辑（改测试点、改题面）。需要决定是否在比赛进行中锁定题目，防止编辑影响进行中的比赛。

## 决策

比赛运行中**不锁定**题目：题目可在比赛中被编辑，比赛题目访问与提交只校验身份与报名（已报名 + 时间窗口），不校验题目内容快照。

- 题目被题单 / 比赛引用时不允许物理删除（仅归档），且不自动改变题目在题库中心的可见性
- 用户在题单或比赛中访问题目时，按题单或比赛本身的访问权限展示题面

## 原因

- 比赛题目编辑是低频、人工审慎的操作，锁定带来的实现复杂度（题目快照 / 版本化）高于收益
- 引用关系保持「引用即指同一条题目记录」，题目变更对所有引用方生效，语义简单可预期
- 比赛中改题属于操作者责任，权限已限缩到题目管理角色

## 替代方案

- **比赛开始后锁定题目（只读）**：被否决——需引入快照或状态锁，复杂度高，且实际需求未提出
- **比赛题目快照版本化**：被否决——MVP 阶段收益低

## 影响

- `contests` / `contest_problems` 不设锁定字段，无题目快照
- 比赛题目访问与提交的越权校验只依赖报名与时间窗口（见 `docs/contracts/contests.md`）
- 若未来需要快照，再引入比赛题目版本表（本决策不排除该演进）
