怎么用

这个节点负责执行用户代码。它主动连接后端 gRPC 网关，不需要对外开放判题端口。本页只绑在本机回环（127.0.0.1:18080）。

第一次连上

  • 地址填网关的 主机:端口。本机 Docker 一般是 host.docker.internal:50051。
  • 令牌必须和后端 JUDGE_GATEWAY_TOKENS 里的某一个完全一致。
  • 点「测试连通」只检查 TCP 能否连上，不验证令牌、也不做 TLS 握手。
  • 点「保存」。改了地址 / 令牌 / TLS 会自动重连；只改容量不会断线。
  • 顶栏变成「已连接」才算注册成功，之后才会收到题目。

状态

  • 已连接 已向网关注册，可以判题。
  • 连接中 正在建立通道（第一次连）。
  • 重连中 断开后或点了「重连」，正在重新注册。
  • 断开 未连上。原因会写在状态栏：后端没开、令牌错误、或 TLS 不对。

TLS

只决定连网关时要不要加密，不限制端口。端口以地址栏为准，例如 oj.example.com:443 或 oj.example.com:8443。生产若用 nginx 把 gRPC 挂在 HTTPS 同端口，再勾 TLS。本机 / 内网明文 :50051 不要勾。

容量

  • 并发 这台机器同时判几份提交。太大容易把容器内存打满（默认限制 1g）。
  • 并行测试点 一份 IOI / 练习题里同时跑几个测试点。ACM 比赛仍是失败即停、串行。
  • 缓存上限 题目数据本地缓存，超出按最近使用淘汰。0 表示不限制。

配置会丢吗

保存写入容器 /cache/node.runtime.toml（已挂载卷），优先于 compose 环境变量，重建容器后仍在。改完若顶栏还是旧值，刷新本页即可。
