# Claude 项目指令

本文件是 Claude Code 专属的项目指南。在使用 Claude Code 编辑此仓库之前，先阅读本文件。

## 上下文文件

先读 `README.md` 了解项目目的，再按任务范围读相关文档：

- `docs/architecture.md` — 技术栈、分层、编码规范、安全规则、权限矩阵
- `docs/contracts/` — 数据模型、API 契约、错误码
- `docs/operations.md` — 测试、部署、环境变量
- `docs/workflow.md` — 文档读取/同步工作流与输出格式

## 行为规则

- 实现模糊需求前先解释你的假设
- 保持代码变更与 `docs/` 文档一致；API 行为变更时同步更新契约、错误码和测试
- 越权与安全：所有用户数据查询必须带 `WHERE user_id = ?`；测试点期望输出、沙箱内部路径不返回前端
- 代码执行仅在 nsjail 沙箱进行；AI 修改代码必须用户确认后应用
- Demo 代码优先可读性，不做过度抽象
- Claude Code 专属行为写在本文件

## 决策记录

在做影响架构的修改之前，先阅读 `docs/decisions/` 目录下相关的决策记录。理解已有决策的原因；若新方案与已有决策冲突，先与用户讨论。

## 输出要求

- 在最终回复中列出所有修改过的文件
- 说明运行或跳过了哪些验证命令
- 绝不谎称测试通过——只有实际运行了测试才能这么说
