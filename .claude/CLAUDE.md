# Claude 项目指令

本项目的**唯一权威指南是仓库根目录的 `AGENTS.md`**：必读顺序、工作规则、决策记录约定、验证命令与领域约定均以它为准。`docs/` 目录下的文档是产品契约，代码、测试与文档保持同步（工作流见 `docs/workflow.md`）。

本文件只维护 Claude Code 专属的补充规则，不复制 `AGENTS.md` 内容；两者冲突时以 `AGENTS.md` 为准。

## Claude Code 补充规则

- 实现模糊需求前先解释你的假设
- Demo 代码优先可读性，不做过度抽象
- 在最终回复中列出所有修改过的文件
- 说明运行或跳过了哪些验证命令；绝不谎称测试通过——只有实际运行了测试才能这么说
